# EVORACING motorcycle parts landing page

This is a static HTML/CSS site. Product images are stored in `assets/` and are deployed with the page.

## GitHub Pages setup

1. Create a GitHub repository and push this project to its `main` branch.
2. In the repository, open **Settings > Pages**.
3. Set the publishing source to **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` deploys on every push to `main`.

The published address is normally `https://<owner>.github.io/<repository>/`.

Before publishing, replace the temporary `https://line.me/` contact links in `index.html` with the shop's LINE account URL.
